## Ano 'to

Ginagamit ang number pag kapareho ng tunog nito ang isang syllable. "D2" ay dito kasi D plus two, "fud3p" ay foodtrip kasi "three" ang "trip." May Tagalog numbers din, kaya "kar4d4" para sa karapat-dapat kasi apat ang 4.

## Saan galing

Number homophones ang tawag dito ng Wiktionary, pang-text messaging. Halimbawa, ang "d2" ay compound ng D at 2 na ginaya ang bigkas ng "dito." Nakalista rin doon ang "10nta" para sa "saan pupunta?"

## Halimbawa

> d2 n q s labas
>
> fud3p tau mamaya?
